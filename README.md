# Agenda de Fisioterapia

App personal para llevar la agenda, las fichas clínicas, las sesiones y los cobros de pacientes de fisioterapia.

**Abrir la app:** https://eddysilupu-ctrl.github.io/agenda-fisio/

## Privacidad

Este repositorio contiene **solo el código** de la app. Los datos de los pacientes **no se guardan aquí ni en ningún servidor**: viven únicamente en el navegador del dispositivo donde se usa la app. Nunca subas a este repositorio respaldos (`respaldo-agenda-fisio-*.json`) ni otros archivos con datos de pacientes.

## Instalar como acceso directo

- **Android (Chrome):** abrir el enlace → menú ⋮ → *Instalar app* o *Agregar a pantalla de inicio*.
- **iPhone (Safari):** abrir el enlace → Compartir → *Agregar a inicio*.

## Respaldo

En **Ajustes → Descargar respaldo**. Hazlo cada semana y antes de cambiar de dispositivo.

## Archivos

| Archivo | Para qué sirve |
|---|---|
| `index.html` | La app completa |
| `sw.js` | Permite usarla sin internet |
| `manifest.webmanifest` + íconos | Permiten instalarla como app |
| `fuente/agenda-fisio.artifact.html` | Misma app, en la versión que corre dentro de Claude |
